Another Security Key

A FIDO-2 Hardware passkey storing device that revolutionizes authentication with contactless technology. Unlike standard keys that use mechanical buttons (or exposed copper), Utsuwa employs Hall Effect Sensors, to enable secure authentication via magnetic rings or charms - eliminating physical contact and reducing wear.

Built on the RP2354A microcontroller and open-source firmware, Utsuwa features custom PCB artwork, designed on Figma, by me. This device stores FIDO-2 passkeys securely while maintaining a sleek, modern form factor and unique design.

Features

  • Hall Effect sensor for contactless authentication.

  • FIDO-2 compliant security architecture.

  • Custom-designed PCB with unique artwork.

  • Open-source firmware and hardware designs.

Open Source

Utsuwa is completely open-source, available on my GitHub.
